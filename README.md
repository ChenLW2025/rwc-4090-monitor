## 上线目标

服务器每20秒采集，本机每120秒发布，网页每15秒获取公开快照。采样年龄达到180秒必须显示过期；断更表示监控链路未更新，不能据此断言服务器停止。只有实际完成连续传播、错误和过期行为验收后，才更新为已上线。

代码与稿件由豆包执行产出；Codex负责决策、详细计划、实物审查与验收。后续阶段会在这里更新，失败记录也会保留在私有工作目录。
